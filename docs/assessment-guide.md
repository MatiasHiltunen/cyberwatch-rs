# Tehtävien ja arvioinnin ajantasainen ohje

Tämä repositorio sisältää ohjelmistoesimerkin ja sen tekniset selitykset.
**Tehtävänannot, määräajat, palautukset ja arviointi löytyvät toteutuksen Moodlen
Kurssiopas ja oppimateriaalit -sivulta.** Niistä ei ylläpidetä rinnakkaista versiota
tässä repositoriossa. Aiempi erillisen YAMK283-repositorion vaatimus on poistettu
opettajan 22.9.2026 antaman linjauksen mukaisesti.

Aloita [suomenkielisestä esittelystä](course-start-fi.md), jatka tarvittaessa
[paikallisten salaisuuksien ohjeeseen](local-secrets-fi.md) ja tarkastele
[arkkitehtuuria](../ARCHITECTURE.md), [uhkamallia](security/threat-model.md)
sekä [teknistä käyttöönottoa](../deploy/README.md).

`docs/evidence` sisältää myös aiempien ajankohtien mittauksia. Niitä ei pidä
tulkita tämänhetkiseksi ympäristöksi tai omiksi opiskelijanäytöiksi. Tässä
paketissa tehdyt muutokset on kuvattu [version tiedoissa](../COURSE_REVISION.md).
