Copy for one actual test or exercise. Do not mark a run passed until it was executed and its result inspected. Delete instructional placeholders from a completed record; preserve unknowns as unknown.

For a tabletop add actual participants/roles, chronological injects and decisions, disagreements, communication, what was simulated versus executed, restoration verification, changed risk assumptions and retrospective action. For an exception add scoped rule/advisory/resource, compensating control, accountable approver and expiry. No permission or risk acceptance is supplied by this template.
